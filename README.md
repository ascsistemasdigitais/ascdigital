# 🚀 ASC Digital Sistemas | Sistemas que organizam sua oficina e aumentam seu lucro

> **Site oficial no ar:** https://ascsistemasdigitais.github.io/ascdigitalsistem/

Eu sou o Alexandre, Eng. da Computação e criador da ASC Sistemas Digitais. Criei este site do zero para apresentar minhas soluções para donos de oficinas, donos de pequenos mercados e também empresas de diversos segmentos, que ainda sofrem com controle no papel ou planilha.

### 🔧 O que eu entrego

**Meu carro-chefe é o Sistema de Gestão para Oficina Mecânica:**
- OS com numeração automática (nunca mais duplica mesmo com 2 funcionários usando)
- Cliente > Veículos > OS tudo amarrado
- Faturamento automático e histórico por placa
- Log de auditoria - você sabe quem criou ou alterou cada OS

**Outros serviços:**
- Criação de sites e landing pages que vendem
- Sistemas personalizados em Java + Firebase
- Digitalização de processos manuais
